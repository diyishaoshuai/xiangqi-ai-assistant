# 历史安装版维护

自 `2026.08.31-portable` 起，当前交付形式为单文件 `XiangqiAI.exe`，**不再构建或发布安装包**。正常开发和发布请使用根目录 `XiangqiAI.spec`，不要使用本目录生成新版本的安装包。

本目录保留旧安装版的维护代码：

- `XiangqiAI.iss`：原 Inno Setup 定义，保持旧版 AppId，供历史安装维护使用。
- `uninstall_support.iss`：按精确路径退出旧程序、检查文件锁及处理已知生成文件；遇到无法安全卸载的锁定文件时提前中止，保留卸载入口。
- `runtime_guard.py`：旧目录版使用的安装维护事件检查钩子。
- `verify_installer.ps1`：历史安装/卸载回归脚本，不属于单 EXE 成品验证流程。

保留这些文件不代表新 EXE 会执行安装或卸载操作。新版本不创建卸载记录、快捷方式、服务、自启动项或计划任务，也不会自动清理已有安装版。

迁移前请退出所有程序副本，并备份 `%LOCALAPPDATA%\XiangqiAI`；旧卸载器可能清理共用的用户数据。请将新 EXE 放在旧安装目录以外，完成旧版卸载后再恢复需要的识别模板。不要对未知目录进行递归清理。
