# v2026.08.31-portable · 单 EXE 免安装版

本版将默认交付方式改为 **Windows x64 单文件 `XiangqiAI.exe`**，不再发布安装包。保留截图识别、棋盘编辑、自动分析、跟随首选着、执黑视角和 `F1` 自动接管等现有功能。

## 下载

- 在本次 Release 的 **Assets** 中下载 `XiangqiAI.exe`（约 171 MiB），双击运行；分享给别人也只需这一个文件。
- 不需要 Python、另下 Pikafish、ONNX 模型、`_internal` 目录或安装程序，使用时完全离线。
- `SHA256SUMS.txt` 是可选校验文件，不是运行依赖；GitHub 自动提供的 Source code 压缩包不是运行版。
- 目标系统：Windows 10/11 x64；本次在 Windows 11 x64 验证。引擎要求 CPU 支持 SSE4.1 和 POPCNT。

## 主要变化

- 引擎、NNUE、识别模型、运行库、使用说明和许可证嵌入同一个 EXE；新增“帮助”菜单，在程序内阅读说明和许可证。
- EXE 所在目录保持干净，日志和识别学习数据统一存入 `%LOCALAPPDATA%\XiangqiAI`，从只读程序目录运行也不要求写入旁边的文件。
- 自动日志保存在 `logs\xiangqi-ai.log`，单份约 2 MiB，保留 3 份历史日志，合计约 8 MiB。达到上限自动轮转，多开时串行写入；无需手动导出，不自动上传。
- 继续读取已有的 `recognition_templates.json`，兼容早期备用目录中的模板；学习数据不保存截图。
- 增加启动版本和异常诊断日志；改进引擎退出过程，防止退出期间的迟到任务重新启动引擎。
- 保留 `F1` 启停、用户操作或切屏时暂停并恢复、重新确认落子、对局结束等待下一局等接管行为。本版更换封装方式，没有改动象棋规则、自动接管决策或模型文件。

## 验证范围

- 单元测试：48 项，47 项通过，1 项因缺少原作者本机截图夹具而跳过。
- 成品运行 13 组内置功能自检，其中自动接管检查包含 21 项模拟测试，不操作真实鼠标或游戏。
- 单 EXE 集成验证：108 项断言通过，包括中文/空格路径、只读程序目录、隔离外部 Python 和引擎依赖、真实模型推理、两张棋盘图片识别对比、资源哈希一致性、正常 GUI/引擎退出、工作子进程异常退出后的回收、日志多进程轮转和学习数据保留。
- 单文件版与原目录版的引擎、NNUE 和两份 ONNX 模型逐字节一致；源码运行与打包运行的样例识别输出一致。

上述结果为本机测试和模拟验证，不代表所有 Windows 版本、硬件或游戏客户端均已实测。

## 升级与注意事项

- 从单文件版升级：退出程序后替换 EXE，用户数据保留。
- 从旧安装版迁移：先退出所有副本并备份 `%LOCALAPPDATA%\XiangqiAI`，再处理旧版卸载。新 EXE 请放在独立目录；旧卸载程序可能清理共用的数据目录，完成卸载后再恢复需要保留的模板。
- 单文件版不会自动卸载旧版，也不会自动清理其他电脑上已有的卸载残留。旧 Release 保留供历史查询，本次无需下载其 ZIP 或安装包。
- 运行时需要数百 MB 的临时解压空间，启动可能稍慢；正常退出后自动回收。断电或整个进程树被强制结束可能留下临时目录，“单文件”并不代表完全不产生临时文件。
- 日志和学习数据不会随退出或删除 EXE 自动清空。彻底移除数据时，先退出所有副本，再删除软件专属的 `%LOCALAPPDATA%\XiangqiAI`，不要删除整个 AppData。
- 本版没有代码签名证书。请核对来源及同一 Release 中的 SHA-256；遇到安全软件明确告警时停止运行并反馈，不建议关闭防护。
- 仅用于单机、复盘、学习或规则允许的场景。

使用方法与问题反馈见 [README](https://github.com/diyishaoshuai/xiangqi-ai-assistant#readme) 和 [Issues](https://github.com/diyishaoshuai/xiangqi-ai-assistant/issues)。
