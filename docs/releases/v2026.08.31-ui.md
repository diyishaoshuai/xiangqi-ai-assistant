# v2026.08.31-ui · 界面优化版

本版重做象棋工作台的布局和视觉样式，继续采用 **Windows x64 单文件 `XiangqiAI.exe`**，无需安装。象棋引擎、识别模型和 F1 自动接管流程保持不变。

## 下载与升级

- 在本次 Release 的 **Assets** 中下载 `XiangqiAI.exe`（约 171 MiB），双击运行；分享时也只需这一个文件。
- 已使用单文件版的用户：先退出程序，再替换 EXE，已有日志和识别学习数据保留。
- 不需要 Python、额外引擎、模型或 `_internal` 文件夹。`SHA256SUMS.txt` 仅用于可选校验；Source code 压缩包不是运行版。
- 目标系统为 Windows 10/11 x64；本次在 Windows 11 x64 验证。CPU 需支持 SSE4.1 和 POPCNT。

## 界面变化

![新版象棋工作台](https://raw.githubusercontent.com/diyishaoshuai/xiangqi-ai-assistant/v2026.08.31-ui/docs/images/workspace.png)

- 统一浅色工作台、青绿色主要操作、暖色棋盘及字体、间距和控件状态。
- 顶部集中截图识别、文件导入和自动接管 F1；底部保留运行状态、置顶、日志和使用说明。
- 棋盘随窗口缩放，棋子、推荐箭头、落点和执黑翻转保持同步；执棋方、轮次与撤销/重做始终可见。
- 右侧分为“引擎分析”“摆局工具”“FEN”三个页面，小窗口下可滚动，支持 Ctrl+Tab 切换。
- 分析页增加推荐着法卡片和明确的思考/空闲状态；思考时间以秒显示，底层参数不变。更换局面时清除旧候选和箭头，避免误用旧结果。
- 摆局棋子按红黑两排排列，保留原有编辑功能；截图识别底图可隐藏或显示。FEN 输入支持 Enter 载入。
- 新增界面回归自检；修正旧跟随自检必须有两步推演的假设，短搜索仅返回一步推演时也能验证正常跟随。

## 保持不变

- 截图识别、自动分析、跟随首选着、循环和连续将军保护、执黑视角及 F1 接管继续保留，没有增加新的运行依赖。
- EXE 旁边不写日志或学习数据；自动日志仍位于 `%LOCALAPPDATA%\XiangqiAI\logs`，单份约 2 MiB，另保留 3 份历史日志，合计约 8 MiB。
- 识别学习数据仍位于 `%LOCALAPPDATA%\XiangqiAI\recognition_templates.json`，不随升级清空，也不会自动上传。

## 验证范围

- 65 项单元测试：64 项通过，1 项因缺少原作者本机截图夹具而跳过；其中包含 17 项界面回归和 21 项接管模拟检查。
- 成品通过 14 组内置功能自检及 113 项单 EXE 集成断言，覆盖中文/空格路径、只读程序目录、隔离外部依赖、真实模型推理、源码与成品识别及资源哈希对比、正常退出清理、工作子进程异常退出后的回收、日志轮转和学习数据保留。
- 单文件版与原目录版的引擎、NNUE 和两份 ONNX 模型逐字节一致；实际窗口截图检查覆盖不同窗口尺寸、执黑视角、三个侧栏页面及 125% 缩放。
- 自动接管测试使用模拟 Win32 接口，不向真实游戏发送点击。以上为本机和模拟验证，不代表所有电脑或游戏客户端均已实测。

## 注意事项

- 启动仍需要数百 MB 临时解压空间，正常退出自动清理；断电或整个进程树被强制结束可能留下临时文件。单 EXE 不代表完全不写磁盘。
- 不再提供安装包，也不会自动清理旧安装版残留。从旧安装版迁移前请先备份用户数据，将新 EXE 放在独立目录，避免旧卸载器删除共用数据或新程序。
- 本版未签名，请核对来源和同一 Release 的 SHA-256；遇到安全软件明确告警应停止运行并反馈，不要关闭防护。
- 仅用于单机、复盘、学习或规则允许的场景。

完整使用方法见 [README](https://github.com/diyishaoshuai/xiangqi-ai-assistant#readme)，问题反馈请使用 [Issues](https://github.com/diyishaoshuai/xiangqi-ai-assistant/issues)。
