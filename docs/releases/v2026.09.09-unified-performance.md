# 统一走棋安全与本机 CPU/GPU 性能配置

## 正确性

- 界面跟随首选着与屏幕自动接管使用同一合法性、风险、完整搜索结果复核流程。跟随时固定单主变化，不再浅搜多候选后自行换着。
- WDL 为零仅表示估计权重，不再宣称必败、劝降或停止补录；重复局面暂停也只显示状态，不弹窗口。
- 走棋工具拒绝错误轮次和非法走法；合法输入延续历史，只有明确导入/摆局才重建历史。
- 基础搜索与安全复核共享 3/5 秒搜索档位预算（识别、启动、点击、调度时间另计）；取消或局面版本变化不会发布旧结果。
- 对手回合按主变化中合法的预测回复，执行一次有时间上限的预搜索；只有视觉确认后的棋盘、行棋方、完整历史和预算全部吻合才复用。预测不会创建点击事务，未命中则取消重算。

## 资源与实测

Core 7 240H、16 逻辑线程、RTX 5060 Laptop、32 GB RAM 本机测量，不代表其他电脑或棋力增幅：

- 3 个局面、每组 2 次、每次 1 秒、打乱顺序，共 54 次冷搜索。8 线程/256 MB 的节点数中位数 4,943,132.5；14 线程/256 MB 为 6,633,675，约增加 34.2%。搜索深度与棋力不保证同比提高。
- 12 线程/256 MB 为 6,189,038。1 GB、2 GB 缓存没有短搜索吞吐收益，未默认加大。
- 同一组 12 张本地 JJ 诊断裁剪回放，CPU 与 DirectML 识别棋子结果一致；完整识别耗时中位数 174.91 ms → 138.97 ms，约减少 20.5%。不含截图和点击，不是整个落子流程提速比例，也不是实盘正确率证明。
- 本机用户目录 `performance.json` 配置为 14 线程、256 MB、GPU 设备 0。在本机设备枚举中设备 0 是 RTX 5060。其他电脑缺省使用 CPU 识别，不能照搬设备编号。

Windows 包内置 ONNX Runtime DirectML 1.24.4，无需安装 CUDA。GPU 首次输出与 CPU 进行数值和分类一致性校验，失败、非有限值或运行异常均降级 CPU。禁用 ONNX Runtime 遥测；模型和引擎本地运行，诊断图不上传。

实测成品首次 GPU 模型初始化和校验约 5.2 秒，后续两帧约 143/137 ms。首次加载不属于 3/5 秒引擎搜索预算，也不是每步都能在 3 秒内完成的承诺。
