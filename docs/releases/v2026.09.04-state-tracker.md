# 2026.09.04 连续棋局状态跟踪版

这一版重构自动接管的确认核心，重点解决 JJ 象棋移动动画、选中/将军光效和终局遮罩造成的重复落子或长期静默等待。

## 行为变化

- DXcam 以 20 FPS 连续获取桌面帧；不可用或运行失败时自动回退 Pillow。
- 锁盘后使用棋盘区域像素变化和 Lucas–Kanade 光流跟踪动画与小幅窗口移动，漂移超过半格才重新完整定位。
- 保留 ONNX 的 90×16 概率输出，分别形成空位、阵营、棋子、遮挡和运动证据。
- 合法状态估计器只比较当前局面、合法一步、已发送着法、对手快速回复和终局，不再要求每帧 90 格全部正确。
- 落子采用不可重复事务；终点点击发送后，无论看到动画、旧局面还是噪声帧，都不会再次发送同一步。
- 3 秒未确认时保存限量本地诊断并切换恢复策略；8 秒后进入低频安全观察。异常只更新状态栏，不弹模态窗口。
- JJ、天天象棋使用独立动画/遮罩参数，未知平台使用保守通用配置。

## 隐私与诊断

诊断仅包含最多 12 帧棋盘裁剪、概率矩阵、事务状态和原因，保存在 `%LOCALAPPDATA%\XiangqiAI\diagnostics`。最多保留 5 个事件或 100 MB，不会自动上传，并可从设置中一键清除。
