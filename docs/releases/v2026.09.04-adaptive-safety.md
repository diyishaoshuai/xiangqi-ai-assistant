# 2026.09.04 自适应棋力与防送子复核版

这一版在连续视觉状态跟踪之上重构自动接管的引擎决策层，重点解决 0.5 秒浅搜直接执行、候选数分散算力，以及评分/PV 与最终着法错配造成的送子行为。

## 行为变化

- 自动接管先按“基础思考”进行单主变化搜索；普通稳定着保持原速度。
- 深度不足、根着不稳定或 PV 暗示丢大子时复核到 3 秒；车炮马存在明显战术风险、以大换小或局面明显不利时复核到 5 秒。
- 静态子力检查只触发更深搜索。若深搜仍选择弃子，程序尊重引擎结论，不以简单规则覆盖战术。
- UCI 输出按完整深度迭代归组，确保执行着法使用同一轮的评分、WDL 和 PV；半截深度不能直接授权点击。
- 自动接管固定使用 `MultiPV=1`。避循环和避连将改用 `searchmoves` 单独深搜，并在替代着没有明显恶化时才采用。
- 基础搜索与安全复核都响应 F1；取消后不创建鼠标事务。

## 对局恢复

- 最后确认局面、完整 UCI 着法历史和已发送终点的待确认事务保存到 `%LOCALAPPDATA%\XiangqiAI\autoplay-state.json`。
- F1 或程序重启后必须由视觉局面合法衔接才恢复历史；不同平台、新局、损坏或过期记录会被丢弃。
- 如果重启时游戏仍显示落子前动画帧，程序保持事务锁定并继续观察，不会重新发送同一步。

## 验证

- 加入本次败局中的车换炮与漏救炮回归，并验证 5 秒结果替换浅搜着法。
- 覆盖 UCI 半截深度、MultiPV 不完整、`searchmoves`、正确弃子、F1 取消和跨进程事务恢复。
- 视觉确认、终局处理和目标点击最多一次的既有约束保持不变。
- 188 项源码回归测试全部通过（1 项仅在提供外部样本时运行）。
- Windows 单文件成品通过 15 组内置自检和 111 项隔离集成断言。
