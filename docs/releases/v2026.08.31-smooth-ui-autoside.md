- 在本次 Release 的 **Assets** 下载 `XiangqiAI.exe`（约 172 MiB），退出旧版后替换 EXE 即可；已有日志和识别学习数据保留。
- 分享时只需 EXE 一个文件。`SHA256SUMS.txt` 用于可选校验；Source code 压缩包不是运行版。
- 目标系统为 Windows 10/11 x64，本次验证环境为 Windows 11 x64；CPU 需支持 SSE4.1 和 POPCNT。

## 自动判断我的执棋

- “我的执棋”旁的 **自动** 默认开启。导入截图或按 F1 接管时，将识别到的将帅映射回原游戏截图，以下方一侧作为我方，自动同步执红/执黑和助手视角。
- 复用现有 ONNX 推理与坐标映射，不额外运行模型或增加固定等待时间；不根据助手已翻转的棋盘反推我方。
- 点击“执红 / 执黑”可改为手动选择，重新打开“自动”即可恢复自动判断。
- 双方将帅或画面坐标不可靠时显示待确认，不贸然点击；新局重新识别，点击前朝向发生变化会停止并提示。
- **执棋方不等于当前轮次。** 标准开局红先；中途接入棋局时，请单独核对“当前轮次”。仅有 FEN 或手动摆局时没有原图朝向，不据此猜测执棋方。

## 接管响应优化

- 改进 F1 开关、停止接管后的窗口恢复和点击前安全检查。
- 将稳定画面确认与引擎思考并行，复用棋盘区域，加入逐像素快速复核，减少重复识别与固定等待。
- 搜索与补充分析共享设定时间预算，避免 0.5 秒设置被额外搜索拉长；真实识别、游戏动画和点击确认仍会有耗时，不代表每步总时长固定为 0.5 秒。
- 保留前台窗口检查、停止取消、防重复点击、循环与连续将军保护等机制。

## 注意事项

- 日志及识别学习数据仍保存在 `%LOCALAPPDATA%\XiangqiAI`，不会写到 EXE 旁边，也不会自动上传。
- 单文件启动需临时解压空间，正常退出会清理；非正常断电或强制结束整个进程树可能留下临时文件。
- 本版未签名，请核对来源及本 Release 的 SHA-256；遇到安全软件明确告警请停止运行并反馈，不要关闭防护。
